# 彩色线描与顺形短排线

适用于用户选择的彩色干笔、短排线、水果果肉、果皮、叶脉等画法。它与 [水彩晕染](light-watercolour.md) 是可选方向；不要自动给同一画面叠满所有媒介效果。参考 [四种水果试稿](../examples/studies/loose-fruits-v2/fruit-sheet.png) 与 [生成脚本](../examples/generators/loose_fruit_studies.py)。[旧橘子](../examples/studies/peeled-mandarin-v1/artwork.png) 保留用于比较；用户指出它过于规整、像切开的剖面，不应作为整颗剥皮橘子的形体范本。

## 形体决定笔触

先辨认物体是完整圆体、剖面还是翻折的薄片。完整橘子的果瓣沿球面转折，果心偏上；不能简单用均匀放射线画成切面。果皮的外表与内侧白瓤需要不同的线向和密度。先定轮廓、翻折关系与遮挡，再排短线。

颜色主要由笔触形成：果肉用相近的橙、金黄与少量赭色，果皮用深浅绿，白瓤用少量暖灰米色。线条本身可以有色，不必再加一圈黑色描边。先确定用户配色，这组颜色只属于橘子例子。

把短线组织成沿形体走的小束：弧度、长短、间隔随表面转向变化。允许局部线相连成较重的色块，同时留下一些宽窄不一的白缝。不要机械铺成等距格子、均匀放射图或全图同角度排线。参考有短笔色块时，不要一味把笔触变得细碎稀疏。

## 松散不是平均加随机数

整颗果实先画不对称外形和沿体积转折的长缝，再独立安排短线；不要共用一个极坐标网格生成所有果瓣和排线。线束只在局部相似，换区域后改变长度、方向、间隔和覆盖度，允许有少量连成块的重笔和较大的安静区域。主要轮廓可断开，但果皮根部、翻折和接触点必须有足够线索。

分别观察题材：梨有偏斜的细颈与饱满下腹；桃子两侧不等大，沿弯曲果缝转折；草莓向下收尖，表面更适合短碎色笔与分散的籽窝；不要照搬橘瓣的长纤维线束。籽窝用少量断开的深红弧线和纸白表示，避免每颗籽都套完整圆圈。不要只把同一个圆形排线模板换色。

## 纸白是结构

果瓣之间的膜、橘络与高光优先不画，直接保留纸面。对背后果皮线条做几何裁切，不能因为前面的果肉没填底色，就让背后线从白缝穿出来。新脚本的 `mask_for` / `texture(..., holes=...)` 展示这一做法；橘子先从果皮排线范围扣去果肉，草莓先在红色范围为叶冠留白。换形状时需换对应的遮挡边界。

## 用现有笔刷实现

使用 `engine:"pencil-case"` 和原版 `ink`。把手写的弧线控制点经 `curve` 或 `bezier` 采样后传入，采样结果不要再次开启 `smooth`。复杂排线可在生成脚本定义跟随曲面的坐标函数，再生成普通 `ink` 路径；保存脚本与 JSON。

在约 1000 像素画布上，可从主轮廓 2–4 像素、短色笔 3–6 像素、`wobble:.3–.7`、`gaps:.015–.04`、`gap_length:[1,2]` 开始。短笔使用 `step:.7–1`，避免采样步长把短线吃掉。笔宽、间距随画幅调整，数量由所需覆盖度决定，不设固定笔数。少量断墨即可，不用大幅抖动模拟手绘。

`hatch` 的固定角度适合局部平面，弯曲果瓣更适合显式 `ink` 路径。这里不需要增加渲染器类型，也不需要用整块水彩填色替代排线。若用户需要纸纹，可另选纸色和 grain；本例沿用白底，只给接触处很轻的影子。

## 看图后检查

缩小看是否仍像具体物件，放大看线束是否跟随形体、是否有整齐条带或背后线穿出。整颗水果若像切面，先修改轮廓、果心位置与果瓣曲线，增加噪点不能解决体积问题。交付试稿与可改源文件，不把一次样张写成用户已接受的固定画风。

## 复现本组

```bash
python3 examples/generators/loose_fruit_studies.py --out output/loose-fruits
```

可用 `--fruit mandarin|pear|peach|strawberry` 单独渲染。全部渲染时额外输出双列对照图；每张保留 `scene.json`、图片、图层与 manifest。这组已被用户选为可保留的案例；其中草莓另有 [纹理修订版](../examples/studies/strawberry-texture-v3/artwork.png) 和 [局部修改脚本](../examples/generators/strawberry_texture_study.py)。使用草莓案例时优先看修订版，其他水果仍保留原稿。认可这些案例不等于所有题材都采用同一种笔触。

```bash
python3 examples/generators/strawberry_texture_study.py --out output/strawberry
```
